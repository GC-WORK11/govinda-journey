# L01 — The first step (3D game)

Verb: TAP. Four dark clay lanterns stand in the front play space; tap each to light it.
Each tap = squash + emissive ramp + point light + leaf burst + rising blip; a warm spark
flies from the previous lamp (or the gate for the first) and leaves a glowing line on
the grass. All four lit -> chime -> onWin.

Files: src/levels/L01/Play.tsx (game), src/levels/L01/lanterns.tsx (shared lamp positions,
Lantern visual, lit/dark materials, halo texture), src/levels/L01/Diorama.tsx (reuses the
same lanterns at the same spots; hides them while `active` so the swap is seamless),
scripts/qa/L01.mjs (taps lamp heads via __journey.find, back-to-front, retry round).

Gotcha worth knowing: THREE.Sprite is raycastable — the 0.9-unit halo was eating taps
meant for other lamps (Tappable swallowed them, deadlock). Fixed with raycast={() => null}
on the halo sprite. Any glowing sprite near a tappable needs this.

Verified: tsc clean; level-check PASS (WON desktop + mobile, 0 console problems).
