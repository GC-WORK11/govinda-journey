# L02 "Rejections" - Completion Notes

## Mini-game
Stepping stones: drag 5 rejection letters ("No", "Not this time", "Not now") from above the water gap onto the water surface. Each letter folds and transforms into a flat stepping stone. When all 5 stones are placed, a small figure hops across the stones to the other side and onWin() fires. Takes ~25 seconds to complete.

## What was implemented
- **Game.tsx**: SVG-based drag-and-drop game with proper coordinate conversion between screen space and SVG viewBox
- **Diorama.tsx**: Two stone pillars with wooden gates that swing open when unlocked, revealing a pond with stepping stones
- **L02.css**: Responsive styling with soft gradients matching the clay aesthetic
- **scripts/qa/L02.mjs**: Automated QA script that drags all 5 letters to specific positions in the drop zone

## Fixes applied
1. Fixed SVG transform syntax error (`scaleY()` → `scale(1, y)`)
2. Implemented proper screen-to-SVG coordinate conversion for accurate drag targeting
3. Fixed animation loop to run continuously instead of stopping when no animations active (critical fix - was preventing folding animations and traveler crossing)
4. Improved QA script to spread stones evenly across the drop zone
