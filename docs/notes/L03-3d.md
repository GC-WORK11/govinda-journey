# L03 — First websites (3D)

Game: a wooden easel holds a giant clay browser window (top bar, three warm dots,
address pill). Three chunky pieces — terracotta header bar, blue picture tile
(hill+sun relief), green button — float beside it, shimmering. Drag each onto its
glowing ghost outline; right drops snap in (burst + rising blip), wrong ones spring
home. All three in -> the page warms, a paper cursor flies in and taps the button,
four little clay people pop up -> chime -> onWin (~1.2 s after last drop).

Verb: DRAG. Pieces drag on a horizontal plane at their own slot height (Draggable
`y` = slot y), so each piece only fits its own outline. Drop accepts near the
"apparent" slot centre (drag plane is lifted, so a visually-overlapping drop lands
~0.3 u toward the camera) or the true slot xz.

Files: src/levels/L03/Play.tsx (only), scripts/qa/L03.mjs. Diorama untouched —
its scaffold already covers the market and the win fires its own payoff.

QA: `node scripts/level-check.mjs L03` -> PASS (WON desktop + mobile, 0 console
problems, 3 runs total). QA drags piece->invisible marker groups named
`L03-slot-<id>` placed on the drag plane so drops land exactly in the acceptance
circle. Rough: nothing known; pieces can't overlap wrong slots since each checks
only its own.
