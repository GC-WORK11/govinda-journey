# L06 Remote — 3D game notes

## The game
Tap three task buttons on a clay phone standing near the traveller. Each tap launches a glowing orb that arcs 
from the phone to the laptop across the island. When the orb arrives, the laptop screen flickers (showing 
working blocks stacking) then displays a green checkmark. Complete all three tasks to win.

## The verb
TAP — tap one of three chunky rounded task buttons (leaf, gear, check) on the phone screen.

## Files
- src/levels/L06/Play.tsx (main game, 355 lines)
- scripts/qa/L06.mjs (QA script using find() for named objects)
- src/levels/L06/Diorama.tsx (existing, not modified)

## What works
- Three distinct task buttons with geometric glyphs (leaf, gear, check) in warm palette colors
- Orbs fly along bezier arc with trail sparkles
- Laptop screen flickers and shows working animation (blocks stacking)
- Completed buttons show checkmark overlay
- Wins after all three tasks complete
- Bob/Pop animations for phone and laptop
- Passes QA on desktop (1440x900) and mobile (390x844)

## Rough edges / notes
- Button sizes are large enough for touch (≥0.28 units wide)
- Orb travel time and laptop work animation tuned to feel responsive (~1.2s each)
- Uses named groups (leaf, gear, check) for QA script find() lookups
