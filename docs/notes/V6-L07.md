## What is built (src/levels/L07/)
- `layout.ts` (new): studio layout in V4 island units, K = 5/3.2. The V5 Obstacle maps points with `onIsland`.
- `studio.ts` (new): module state shared by Diorama and Obstacle (landed words, mic open, version).
- `Diorama.tsx` (rewritten): studio hut, laptop screen with the landed words, mic with a halo that lights while the sheet is open, sound-wave ribbons, planting. Blockers stay off the path (|x| < 0.74 in V4 units). The V4 world also mounts this Diorama.
- `Obstacle.tsx` (rewritten): one interactable `L07-speak` (E or tap, radius 2.1). It opens the sheet and freezes the traveller. Each word, accepted in order (aliases hallo, mai, fone), sends its chip on an arc from the mic to the laptop, then types it. After the fourth word the sheet closes, and `complete()` fires 1.4 s later and grants `voice`. Unmount flushes in-flight words. The QA solver is at `window.__journey.solve.L07`.
- `VoiceUI.v5.tsx` (rewritten): Web Speech per word (en-IN, restarts after each result, "say it" button), typed fallback, "type it instead", "not now". A wrong word shows "try: <word>" and the sheet stays open. There is no fail state.
- `kit.v5.tsx`: trimmed to C, clay, BlockBox, makeCanvasTexture and chipTexture. The old door, robot, console and laptop helpers are removed. Static grep: nothing outside L07 imports L07 internals.
- `Play.tsx` (V4 mini-game): only the layout constants moved to layout.ts. Mechanics unchanged.
- Untouched: `Game.tsx`, `dev.v5.tsx`, `dev.html`, `L07.css`.
