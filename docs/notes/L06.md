# L06 Remote

## Mini-game
"From the pocket": A clay phone on the left with 3 task chips ("fix the failing test", "add dark mode", "write the README") and a clay laptop on the right. Tap a task chip → it travels across to the laptop → the laptop screen shows code lines being written with soft monospace text and muted green/red diff lines → progress streams back to phone as short text lines → "Approve" button appears → tap to approve → laptop shows a green checkmark → after 2 tasks are approved, onWin() fires. Takes ~30 seconds to complete.

## Diorama
Small cream house with terracotta roof and open window showing a desk with a laptop inside. On the far edge of the island (~1.8 units away) is a person-sized phone tower/bench structure with a phone shape on top. When unlocked, a dotted arc line animates between the phone tower and the house window, and the laptop screen flickers with a subtle animation.

## Notes
- The mini-game uses hardcoded hex colors instead of CSS variables for better contrast and visibility
- Coding animation takes ~4 seconds (travel 1.2s + 5 progress lines at 0.7s each + approve screen 0.6s)
- QA script waits 8 seconds for approve button to handle the full animation sequence
- Diorama uses TypeScript type casting for material opacity to fix type errors
- Signal line between tower and house uses 12 animated dots in a quadratic bezier curve
- All interactive elements have `data-qa` attributes for automation
