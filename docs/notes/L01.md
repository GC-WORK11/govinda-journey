# L01 — The first step (IIT Patna · 2023)

## Mini-game
"Light the lamps": an SVG evening campus — path, gate, campus block, banyan, four clay
lamp posts. Tap each lamp to light it (warm glow, flame flicker); after the 4th the dusk
veil lifts to dawn (sun rise, windows light, birds) and `onWin()` fires. ~10–15 s.
Stray taps make unlit lamps ring softly. Hint: "Tap each lamp." + 4 progress dots.

## Notes / rough edges
- Gotcha worth knowing: the roof cone is rotated via `geometry.rotateY` then mesh-scaled.
  Doing rotation on the mesh instead makes scale apply pre-rotation → the footprint becomes
  a kite and a corner poked through the scaffold cloth. Fixed; worth copying if other
  levels squash rotated cones.
- Scaffold is intentionally roomy ([2.4, 2.05, 1.62]) so the hip roof stays inside the
  cloth including its rounded corners.
- Lamp heads/windows use module-level emissive materials with a gentle flicker in
  useFrame; flicker + smoke are skipped under prefers-reduced-motion.
- One pointLight (warm, distance 3) turns on at unlock — cheap, only when solved.
