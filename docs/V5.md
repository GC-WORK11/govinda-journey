# The Journey of Govinda — V5

A walkable 3D story. You control the traveller across floating islands, one per chapter of my
life from 2023 to Nov 2026. Each project, once solved, gives an ability that the NEXT obstacle
needs (Metroidvania-lite). It must feel like a game you play, not a video you watch.

## Feel
- Desktop: WASD / arrows to move, Shift to run, Space to jump, drag mouse to orbit, E / Enter to use.
- Mobile: left-thumb virtual joystick, right-side jump + use buttons, one-finger drag on the
  right half orbits. Tap-to-move is a fallback.
- Third-person follow camera, smoothed (critically damped), never clips into terrain, pulls in
  when a blocker is between it and the player.
- Acceleration / deceleration, turn smoothing, coyote time + jump buffer, small footstep dust.
- GLB animations: idle, walk, run, jump, cheer (KayKit Rogue in public/models/student.glb).

Each later obstacle physically requires the earlier ability: e.g. the L03 bridge needs blocks
lifted onto a ledge (climb), the L05 lift path has a gap (build), the smog island's path starts
from the lift top (power), etc. Island agents agree on these hooks via `has(ability)` from core.ts.

## Timeline + story
- A thin ribbon at the top: 2023 … Nov 2026, ticks per island, a small marker moves as you go.
- Sky time of day follows the ribbon (morning at L01 → golden → dusk → night with lanterns at L09).
- Copy: on arriving, the island's `line` (registry.ts) fades in under the ribbon; on solving,
  the `tech` line replaces it for a few seconds. One plain line + one technical line. Nothing else.
- Ability gained: its engraved glyph (thin line icon, not emoji) appears in the bottom-left row.

## Art
- Real CC0 assets, not primitives, for everything visible: KayKit (Adventurers, Dungeon, City
  Builder, Furniture), Quaternius (Ultimate Nature, Stylized Nature, Modular), Kenney.
  Put GLBs in public/models/packs/<pack>/, meshopt/quantize them (gltf-transform if present in
  node_modules, otherwise keep only small files). Total public/ budget: 25 MB, per island ≤ 2 MB,
  lazy-loaded per island.
- One shared toon/clay material (src/v5/art/material.ts): soft wrap lighting, gentle rim, AO.
- Textured stylized cliffs under each island, animated water below, soft clouds, few particles.
- Post: very subtle tilt-shift (or none), light bloom, N8AO. References: Monument Valley,
  Townscaper, A Short Hike, Tiny Glade. Calm, warm, handmade.

## Hard rules
- No confetti spam, no exclamation marks, no "Level complete", no emoji or cartoon icons, no neon,
  no cyberpunk, no boxy panels. Richer and more polished, not busier or cuter. When in doubt, cut it.
- Copy only from src/levels/registry.ts. Never invent metrics. Never name program.
  Do not mention any employer or client under confidentiality.
- Must run on mobile (390×844) and desktop (1440×900). `?lite` disables post FX and shadows.
- Keep the V4 world reachable at `?v4` until V5 is complete.

World5 renders, per island i: `<group position={ISLAND_POS[i]}> <IslandBase/> <Obstacle id active complete done/> </group>`.
Island local frame: top surface at y=0, usable radius 5 (bigger than V4's 3.2). The path runs
from the entry at (0,0,4.2) to the exit at (0,0,-4.2) in island-local coords; the next island is
toward -z. WORLD exports ISLAND_POS, ISLAND_R, ENTRY, EXIT from src/v5/world/layout.ts.
An island's exit stays blocked until its obstacle calls complete() (WORLD draws the bridge).

## Process
- Small commits, only your own files: `git -c user.name="Govinda" -c user.email="<author-email>" commit`.
  Never `git add -A`, never commit others' files, never reset/checkout others' work. Do not push.
- Check before commit: `timeout 120 ./node_modules/.bin/tsc --noEmit -p .` must pass.
- Dev server already runs at http://localhost:5190/ (do not start another). URL: `/?v5&qa`.
- Screenshots/Chrome: ONE Chrome at a time on the box. Use `node /tmp/gj-liveshot.mjs out.png "<url>" [390x844]`
  (lock-aware, profile /tmp/gj-chrome-profile). Never launch Chrome yourself otherwise.
  NEVER run pkill/killall or kill processes you did not start.
- Disk: run `df -h /` before downloads/builds; keep > 1 GB free. Only delete files you created.
- No `npx` downloads, no new npm installs. CC0 asset downloads (zip from kenney.nl, quaternius,
  kaylousberg itch/github) are fine, unzip to /tmp, copy only the needed GLBs, delete the zip.
- Write a short status to docs/notes/V5-<AREA>.md when you finish each step.
