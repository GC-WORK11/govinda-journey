# V6 — expanded game (deadline Nov 4 2026 IST)

Production stays V4+art until V6 passes the release check below. Work on top of V5 (src/v5, src/levels).

## Hard rules (unchanged from V5.md, plus)
- Warm claymation / tiny-town style. No cyberpunk, neon, confetti, emoji, exclamation marks, "Level complete", boxy panels. Fonts Fraunces + Inter.
- Character: warm brown skin, near-black hair, cream shirt, indigo backpack.
- Copy only from src/levels/registry.ts, and every claim must be in docs/FACTS.md with a source and verified=yes. Never mention HUD / datavendors (NDA), Mergetober, or any fellowship program name.
- "When in doubt, cut it." Mobile 390x844 and desktop 1440x900 both work; ?lite fallback works.
- Commit with `git commit -- <your files>` only. tsc must pass. One Chrome at a time via scripts/chrome.mjs withChrome (lock). No pkill. Disk: `df -h /` before any download, keep > 1 GB free.
- Verify by PLAYING (real input), not by teleporting, before you say done.

## Goals
1. Full playthrough 3–5 min, no dead walking. Each level a short, satisfying challenge.
2. Distinct biome per island (no 11 domes): IIT Patna campus (L01), closed gates (L02), weekend workshop (L03), Ent compute yard with four glowing laptops (L05), smoggy Delhi street (L04 Alive), road across India (I02), VOXEL MODERN CITY with a HELICOPTER the player boards and flies (L06 Remote), recording studio / sound-wave island (L07 Wispr Wrap), sign-language plaza (L08 Sign Flow), finale (L09).
3. Pet dog unlocked after the first shipped project (L03), follows with idle/run/sit, rigged CC0 model (Quaternius / KayKit), not primitives.
4. Tight keyboard + touch movement and camera.
5. Perf: instancing, merged statics, < ~150 draw calls, sun-only small shadow map, DPR cap, no per-frame allocations, small initial bundle, islands lazy-loaded + preloaded one ahead, compressed GLBs. Measure: bundle size, draw calls + triangles per level, JS frame time, cold time-to-interactive.
6. How-to-play screen before start (keys/touch, goal), warm style, no boxy panel.
7. Truth audit -> docs/FACTS.md (claim, source URL, verified yes/no). Unverified -> removed or softened.
8. Portfolio first: each project island = simple explanation + one peak technical detail + real repo/demo links. Finale = real portfolio summary (projects, stack, links, contact).
